概念圖組（四）｜體循環、肺循環與淋巴系統

人體雙循環路徑與體液循環連結

【循環口訣與路徑】：「左體右肺、要換邊」。
1. 體循環：左心室 → 主動脈 → 小動脈 → 組織微血管（充氧血變缺氧血）→ 小靜脈 → 上、下大靜脈 → 右心房。
2. 肺循環：右心室 → 肺動脈 → 肺泡微血管（缺氧血變充氧血）→ 肺靜脈 → 左心房。
3. 淋巴系統：血漿自微血管滲出形成組織液 → 流入末端封閉的淋巴管成為淋巴 → 經淋巴結過濾病原體（內含特殊白血球：淋巴球）→ 最後注入鎖骨下方的靜脈重回心血管系統。
