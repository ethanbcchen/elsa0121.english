重點系統整理｜分數四則運算核心法則

一、負分數表示、倒數與運算律

  • 負分數等值關係：當 $a, b$ 為正整數時，$\dfrac{-a}{b} = \dfrac{a}{-b} = -\dfrac{a}{b}$。
  • 比較負分數大小：負分數的絕對值愈大，其值愈小（即若 $a > b > 0$，則 $-a < -b$）。
  • 倒數定義：若兩數的乘積為 $1$，則稱此兩數互為倒數。$\dfrac{b}{a}$ 的倒數為 $\dfrac{a}{b}$（$a, b \neq 0$）；$0$ 沒有倒數；帶分數求倒數須先化為假分數。
  • 分配律與去括號：$a \times (b + c) = a \times b + a \times c$；$-(a + b) = -a - b$，$-(a - b) = -a + b$。
